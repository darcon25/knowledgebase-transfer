**為什麼重要**：這張表的核心不是總量，而是**結構翻轉**：
- **General Purpose CPU 占比 71% → 22%**（五年）
- **Agentic CPU Applications 從 311M（1%）→ 122,545M（52%）**，2026E 單年成長 **3578%**
- CPU 總 TAM 從 290 億美元成長到 **2,374 億美元**，約 8 倍

「Agentic CPU Applications」是一個新開的分類——指 AI agent 工作負載所需的 CPU。
Citi 認為它在 2030 年會超過一半，這是相當激進的假設，**值得記下來日後驗證**。

可放進 [[themes]] 新開一頁「Agentic 運算需求」，並連到 [[2330 台積電]]（CPU 代工）、
[[AGI硬體需求與載板記憶體]]（多 Agent 同時運作是記憶體需求 16× 的原因之一）。
與 [[5et7pf9l]] 的 J.P. Morgan ODM 矩陣對照：ASIC servers 已單獨列出 CPU 欄位（鴻海、英業達供 CPU board）。
