## 內容

**手繪風格資訊圖：AI → AGI「不只是更多的 GPU，而是整個世界的升級」**（版本標記 v4）。
英文副標：MORE THAN COMPUTE. A NEW FOUNDATION FOR A HIGHER INTELLIGENCE.

### 左右對照：現在的 AI vs 邁向 AGI
| | 現在的 AI（v2） | 邁向 AGI（v4） |
|---|---|---|
| 在做什麼 | 訓練模型、回答問題 | 長時間思考、多 Agent 協作、工具調用、長 Context、持續推理、服務全球用戶 |
| 晶片 | NVIDIA **H100**，80GB HBM3，~3.35 TB/s | NVIDIA **Rubin**，288GB HBM4，**22 TB/s** |
| 規模 | **100,000 顆 GPU**，約 **8 PB HBM**（100,000 × 80GB = 8,000,000 GB） | **400,000 顆 GPU**，約 **115.2 PB HBM**（400,000 × 288GB = 115,200,000 GB） |

中間箭頭：**4× GPU／3.6× 單顆記憶體／≈ 14.4× 總 HBM，實際需求還近 16× 或更高**

### 關鍵數據比較
| 項目 | 現在 (AI) | 下一階段 (AGI) | 成長倍數 |
|---|---|---|---|
| GPU 數量 | 100,000 | 400,000 | **4×** |
| 單 GPU HBM | 80GB | 288GB | **3.6×** |
| 總 HBM 容量 | 8 PB | 115.2 PB | **14.4×（約 16×）** |
| 單 GPU 記憶體頻寬 | 3.35 TB/s | 22 TB/s | **6.6×** |

### 為什麼記憶體需求可能 16 倍？（五個原因）
1. **GPU 數量增加 4×**（10 萬顆 → 40 萬顆）
2. **單顆 HBM 容量提升 3.6×**（H100 80GB → Rubin 288GB）
3. **長 Context 推理**：更長的上下文，KV Cache 大幅增加
4. **多 Agent 同時運作**：更多記憶、更多工具、更多中間狀態
5. **高併發全球用戶**：同時服務大量使用者

→ 因此整體記憶體需求逼近 **16× 甚至更高**。

### 從 Compute 到完整基礎設施（各環節升級幅度）
| 環節 | 升級 |
|---|---|
| GPU（算力） | 4× |
| HBM／HBM4（記憶體） | **~16×** |
| HBM Base Die／TSV | ↑ |
| 先進封裝 CoWoS | ↑ |
| CPO／光通訊 | ↑ |
| 高速交換器／NVLink | ↑↑ |
| DDR5／LPDDR | ↑ |
| SSD／NAND | ↑ |
| 電源／散熱 | ↑↑ |

### 關鍵供應鏈（圖下方的傳導鏈）
**GPU**（NVIDIA，算力引擎）→ **HBM**（SK hynix／Samsung，高頻寬記憶體）→ **CoWoS**（TSMC，先進封裝）
→ **CPO／光通訊**（Broadcom／台廠供應鏈，高速互連）→ **交換器**（NVIDIA／Arista，資料流動的樞紐）
→ **PCB／CCL**（台灣供應鏈，連結一切的基礎）→ **電源**（台達／光寶等，穩定的動力）
→ **散熱**（奇鋐／雙鴻等，讓一切持續運作）

> 結語：**真正的瓶頸，正從算力不足，轉向記憶體、互連與資料搬運不足。**
