### 圖 1｜周一美股盤面：Agentic AI 帶動 CPU 主題爆發

一張中文資訊圖（單張，非影片封面），四個區塊。副標：**「資金不是在買『科技普漲』，而是在買『agent 要吃 CPU』」**。
右上角小字標註：**「約 9/21 美股相對大盤表現」**。

#### 區塊 1｜當日跑贏大盤的焦點標的（標題：CPU 三家明顯跑贏 SOXX）

橫條圖，數字為圖上原文（皆為區間值，非單一收盤漲幅）：

| 標的 | 圖上漲幅 | 圖上註解 |
|---|---|---|
| ARM | +12～13% | agent 推升 CPU 授權／伺服器核數 |
| INTC | +9～12% | CPU 短缺敘事再點燃 |
| AMD | +8～10% | CPU 加分，但本身也受 GPU 主線支持 |
| META | +7～9% | Muse + Connect 催化 |
| SOXX | 約 +3% | 整片半導體有漲，但沒三家 CPU 那麼兇 |

區塊底部紅框結論：**「這不是整片晶片普漲，而是『CPU 重估』！」**

#### 區塊 2｜為什麼 Muse 會讓市場想到 CPU？

左右兩欄對照（圖上原文照抄）：

| 傳統大模型訓練 | Agent / Muse 類工作流 |
|---|---|
| 大量平行矩陣運算 | 開瀏覽器、讀頁、填表、呼叫 API |
| GPU / HBM 是主角 | 失敗重試、排程、再開子 agent |
| CPU 多數只是配菜 | 每用戶一個沙盒 / VM |
| — | 吃 CPU、記憶體、磁碟、編排層 |
| 圖說：大規模並行計算，訓練更大的模型 | 圖說：很多 agent・很多任務・很多沙盒，需要大量的 CPU 來協調與執行 |

下方為一條五格傳導鏈：

`Muse 爆紅` → `消費級 agent 被驗證` → `大量常駐沙盒 / 編排` → `CPU 佔比上升` → `ARM / INTC / AMD 重估`

關鍵字列：**控制流、工具呼叫、狀態機、排程、隔離環境**
對話框結論：**市場在交易「Agentic AI 讓 CPU 重新變主角」**

#### 區塊 3｜三家公司怎樣吃到這波？

| 公司 | 一句話定位 | 圖上論點 | 標籤 |
|---|---|---|---|
| ARM | 邏輯最純 | 賣架構授權與權利金；CPU 顆數／核數增加就受惠；不必自己贏 socket，也能抽「架構稅」 | 最純 CPU 敘事 |
| Intel | 彈性最大 | x86 存量最大；雲端 VM／編排層直接受益；但若增量 CPU 轉向 Arm，自身有風險 | 短缺敘事 + 存量優勢 |
| AMD | 受益，但不只靠 CPU | EPYC 吃到 CPU TAM 擴大；但萬億市值主線仍是 GPU 大單；Muse 可解釋超額漲幅，不足以解釋全年大升 | CPU + GPU 雙主線 |

#### 區塊 4｜一眼看懂（三點結論）

1. Muse 令市場重新定價：AI 不只吃 GPU，也更吃 CPU。
2. ARM、INTC、AMD 跑贏 SOXX，反映資金在買「agent → CPU」主題。
3. 這波可以做交易解讀，但要變基本面，仍要看實際 vCPU 使用與雲端需求數據。
