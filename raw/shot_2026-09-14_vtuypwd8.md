**FOMO 研究院（fomosoc.substack.com）圖卡：100G QSFP+ 光模組結構手繪圖解**

畫面為米白紙張上的工程手繪風格，畫出 **InnoLight（中際旭創）TR-FC13T-NPB** 100G 光模組的上下兩個視角，
背景浮水印為三家光模組／光元件大廠的 logo：**INNO LIGHT、COHERENT、LUMENTUM**。

**標註的六個結構重點**
| 標註 | 位置／說明 |
|---|---|
| **GREEN NYLON PULL TAB** | 綠色尼龍拉環（模組前端，用於插拔） |
| **METAL CASING WITH GRIP RIBS** | 帶防滑肋的金屬外殼 |
| **LABEL AREA** | 標籤區，貼有 INNO LIGHT 標籤：S/N M62CSC6M5、型號 TR-FC13T-NPB、"Have Been Certified CLASS 1 LASER PRODUCT"、Made in China |
| **QSFP+ CONNECTOR INTERFACE** | QSFP+ 連接器介面（金手指與卡榫結構） |
| **100G MARKING** | 綠色拉環上的 100G 字樣 |
| （尺寸標註） | 上下兩視角均標示長寬高量測線 |

**對應的貼文文字**（已在原筆記中）：高盛將 2028 年全球光模組市場規模預測上調至 **1,485 億美元**，
並給中際旭創 A 股目標價 2,645 人民幣（隱含超過 200% 上漲空間）。

**這張圖的作用**：把「光模組」這個抽象名詞具體化——它是一個可插拔的硬體模組，
綠色拉環代表 100G 規格（不同速率用不同顏色）。對理解 [[CPO共封裝光學供應鏈]] 有幫助：
**CPO 的意義正是要取消這種可插拔模組，把光引擎直接封裝到交換器晶片旁邊**，
以降低功耗與延遲——所以這張圖畫的其實是「CPO 想要取代的東西」。

浮水印的三家（中際旭創、Coherent、Lumentum）正好是 [[CPO共封裝光學供應鏈]]
「雷射光源」與「ELS／光引擎」兩個環節的主要業者。
