## 內容

**Goldman Sachs Global Investment Research：Global Server market opportunity**——伺服器市場自下而上模型全表。

### 方法論（圖左說明）
- **Global server TAM = 一般伺服器 + AI server racks (NVL72) + AI server (8-GPU)**
- 一般伺服器出貨 = 前六大伺服器品牌 + ODM direct + others；營收 = 各公司出貨 × 各自 ASP
- AI server 出貨 = 前六大品牌 + ODM direct + others；營收 = 出貨 × ASP

### Revenues by type（US$ m）
| 項目 | 2025 | 2026E | 2027E | 2028E |
|---|---|---|---|---|
| **Global server revenues** | 347,913 | 604,117 | 849,860 | **1,102,109** |
| General servers | 147,970 | 189,132 | 221,573 | 245,210 |
| **AI server racks (NVL72)** | 53,916 | 166,673 | 336,140 | **561,402** |
| AI server training (8-GPU) | 123,255 | 205,166 | 215,799 | 219,395 |
| AI server inferencing (8-GPU) | 22,772 | 43,146 | 76,347 | 76,102 |

### Mix（占比）
| | 2025 | 2026E | 2027E | 2028E |
|---|---|---|---|---|
| General servers | 43% | 31% | 26% | 22% |
| **AI server racks (NVL72)** | 15% | 28% | 40% | **51%** |
| AI server training (8-GPU) | 35% | 34% | 25% | 20% |
| AI server inferencing (8-GPU) | 7% | 7% | 9% | 7% |

> **這就是標題的來源：NVL72 機櫃在 2028 年占整體伺服器市場 51%，正式過半。**

### Revenues YoY
總計：2026E **+74%**、2027E +41%、2028E +30%
其中 AI server racks：2026E **+209%**、2027E +102%、2028E +67%

### Shipments by vendor（重點：ODM direct 三雄，k units）
一般伺服器 2028E：Quanta 2,748／Hon Hai 971／Wiwynn 3,404／Others 7,721
（2025 分別為 2,249／895／2,166／6,252）

AI server 8-GPU 2028E：Quanta 145／Hon Hai 431／Wiwynn 277／Others 756（總計 2,558）

**AI server full racks（k racks）2028E**：Hon Hai **113**／Quanta 22／Wiwynn 7／Dell 8／Super Micro 5／Gigabyte 2／Lenovo 3
（2025：Hon Hai 0、Quanta 4；2026E：Hon Hai 11、Quanta 13；2027E：Hon Hai 65、Quanta 17）

> **鴻海在整機櫃（full rack）這一段從 2025 年幾乎是 0，到 2028E 的 113k racks，是全表成長最猛的一格。**
