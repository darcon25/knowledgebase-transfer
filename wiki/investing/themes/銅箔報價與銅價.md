# 銅箔報價與銅價

銅箔是 PCB 的導電層，成本佔比高。銅價與高階銅箔（HVLP，高頻低粗糙度銅箔）報價是這條鏈**最上游的價格訊號**，會依序傳導到 CCL 與 PCB。

## 傳導路徑與時間差

```
銅價上漲 → [[銅箔]] 廠先反應（報價與毛利同步走高）
        → [[CCL]] 廠約一季後轉嫁（能不能轉嫁決定毛利）
        → [[PCB]] 廠看接單與客戶接受度
```

**觀察重點**：銅箔漲、CCL 也漲 = 健康的轉嫁；銅箔漲、CCL 沒漲 = CCL 毛利被壓縮，要警覺。
