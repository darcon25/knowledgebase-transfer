# 知識庫進料管道

這個知識庫目前有四條資料進來的路徑。兩條是既有的（手機／瀏覽器），兩條是 2026-08-28 新增的本機工具。

## 重點

| 管道 | 進到哪 | 怎麼運作 | 狀態 |
|---|---|---|---|
| Threads／Instagram 自動存檔 | `raw/` | 外部自動化產生「已整理過的結構化筆記」，用 `darcon25` 身分 commit 進 GitHub repo，訊息格式 `📥 Archive: <檔名>` | 運作中，**實作細節未明** |
| Obsidian Web Clipper | `Clippings/` | 瀏覽器擴充功能剪網頁 | 運作中 |
| YouTube 逐字稿 | `raw/youtube_<日期>_<影片ID>.md` | `tools/capture.py --youtube <網址>`，用 yt-dlp 抓字幕 | 2026-08-28 新增 |
| 截圖（含 X、限動、付費內容） | `raw/shot_<日期>_<序號>.md` + `raw/assets/` | `tools/capture.py --shot <圖片>`，之後由 Claude 看圖讀出內容 | 2026-08-28 新增 |

## 待查清楚的事

Threads／IG 那條管道的實作位置還沒找到：

- repo `darcon25/knowledgebase-transfer` **沒有 GitHub Actions workflow**
- commit 的 author 與 committer 都是 `darcon25 <chientsungliu@gmail.com>`，不是 GitHub 網頁介面的 `noreply@github.com`
- 內容明顯是 LLM 產生的結構化筆記（開頭常見「這是一份針對您提供的社群媒體貼文內容所做的結構化筆記」）

→ 最可能是**手機端自動化**（iOS 捷徑或 n8n 之類）呼叫 LLM 整理後，用 GitHub API 直接 commit。要新增平台或修改格式時，得先找出這條流程設定在哪。

## 為什麼 X（Twitter）走截圖

未登入抓不到貼文內文，官方 API 每月 100 美元起。截圖管道一條就同時解決 X、限動、付費內容、以及任何看得到但抓不到的東西。
