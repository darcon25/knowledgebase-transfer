# 資料源與限制

每個資料源都有它看不到的東西。**用資料下判斷之前，先確認這個資料源本來就看得到那件事。**
以下限制全部是實測後寫下來的，不是推測。

## 一、市場數據（4 個免費 API）

| 資料源 | 給什麼 | 看不到什麼 |
|---|---|---|
| 證交所月營收 `t187ap05_L` | 上市 1,085 家的月營收、MoM、YoY、累計 | **只有營收沒有獲利**；多角化公司無法拆分部門 |
| 櫃買月營收 `mopsfin_t187ap05_O` | 上櫃 890 家，欄位同上 | 同上 |
| 證交所估值 `BWIBBU_ALL` | 上市 1,081 檔的本益比、股價淨值比、殖利率 | **本益比是過去四季的**，成長股天生偏高；虧損公司沒有本益比 |
| 櫃買估值 `tpex_mainboard_peratio_analysis` | 上櫃 887 檔，欄位名稱不同 | 同上 |
| 證交所營益分析 `t187ap17_L` | 上市 1,041 家的**毛利率、營業利益率、稅前／稅後純益率** | **季度資料**，比月營收慢 1–2 個月；只有比率沒有絕對金額明細 |
| 櫃買營益分析 `mopsfin_187ap17_O` | 上櫃 874 家，欄位名稱不同（注意是 `187ap17` 不是 `t187ap17`） | 同上 |
| MOPS 歷史月營收 `mopsov.twse.com.tw/nas/t21/{sii,otc}/` | 過去每個月的營收報表 | **Big5 編碼的 HTML**，要自己解析；不含成長率欄位（要自己算）；沒有備註欄 |

**四個共同的限制**

1. **OpenAPI 只有當期快照，沒有歷史**。今天不抓，昨天的估值就永遠拿不到了 → `tools/fetch_market.py` 每天存一份到 `data/`，時間序列是自己累積出來的。月營收例外：可以用 `tools/backfill_revenue.py` 從 MOPS 回補（已回補 12 個月）。
2. **不含 ETF**。追蹤的 41 檔裡有 3 檔 ETF（0050、009816、009819）在這四個 API 都查無資料。
3. **日期是民國格式**（`1150827` = 2026-08-27，`11507` = 2026-07），程式已處理，但看原始 JSON 時要注意。
4. **沒有 API key 也就沒有服務保證**。官方可能無預警改格式或停用，健檢的「資料過期」就是在防這個。
5. ⚠️ **櫃買中心（tpex.org.tw）的 SSL 憑證，Python 會拒絕**。它用的 TWCA 憑證缺 Subject Key Identifier，新版 OpenSSL 直接擋掉，但 curl 走 macOS 系統信任庫可以驗過 → `fetch_market.py` 已加 curl 備援（**憑證仍有驗證**，不是關掉檢查）。2026-08-30 首次發生。
6. **月營收的「備註」欄常常藏著關鍵解釋**，很容易被忽略。[[1446 宏和]] 營收 -87.7% 的答案（「本月營建無認列收入」）就躺在這一欄，我第一次分析時漏掉了。

## 二、新聞

| 資料源 | 給什麼 | 看不到什麼 |
|---|---|---|
| Google News RSS | 標題、媒體、連結、發布時間 | **沒有內文**。連結是 Google 轉址；同一則新聞常重複出現 |

**最重要的限制**：RSS **無法判斷真偽**。2026-08-27「PTFE 取代 CCL 傳言」讓台光電急殺跌停——標題抓得到，但「傳言是真是假」抓不到。標題只能當作**該去查什麼**的線索，不能當結論。

另外品質參差：混雜「股市爆料同學會」「盤中速報」這類幾乎沒有資訊量的條目，以及大量純技術面的即時新聞。

## 三、進料管道

| 管道 | 給什麼 | 看不到什麼 |
|---|---|---|
| **手機 Threads/IG 自動存檔** | LLM 整理過的文字摘要 | ⚠️ **有輸出長度上限——15 篇裡 10 篇被截斷**；**完全不存圖片**；是摘要不是原文；貼文失效時會存下 404 頁的摘要（已發生 6 次） |
| **Obsidian Web Clipper** | 網頁全文 | 圖片只存外部網址不下載（原站砍圖就失效）；夾帶廣告 iframe 與導覽列雜訊；同一篇可能重複剪存 |
| **yt-dlp YouTube** | 完整逐字稿 | **沒有字幕就完全空手**；**看不到畫面**（投影片、圖表、示範操作全部漏掉）；自動字幕有錯字與滾動重複；同時抓多語言會被擋（HTTP 429） |
| **截圖管道** | 任何看得到的畫面 | 需要人工截圖；辨識品質取決於圖片解析度；**我讀圖是視覺推論，數字有可能誤讀** |
| **WebFetch 重抓** | Threads 純文字貼文（實測可行） | **圖片內容抓不到**（需登入）；長貼文仍會被截斷；回傳是小模型整理非逐字；**留言區抓不到**——很多乾貨在留言 |

**實例**：`raw/threads_2026-07-14`（十大封裝技術）的內容**在圖片裡**。手機管道 OCR 了一半就截斷、圖片沒存、WebFetch 也拿不到圖 → 這種貼文只能靠截圖管道。

## 四、持倉資料

`Maxtrading Review/data/trades.db`（唯讀借用，不修改該專案）

- 只有台股，加密資產在另外的表
- `positions` 是每日快照，價格是**前一交易日收盤**
- 若 Maxtrading Review 的排程沒跑，這裡的資料就會過期

## 五、分析方法本身的限制

1. **「成長÷本益比」是相對指標**，用來排序與提問，不是估值模型
2. **月營收不等於獲利**，漲價有沒有吃到毛利，月營收看不出來
3. **資料日期不同步**：持倉與估值是前一日收盤、新聞是當日盤中，比較時要注意
4. **目前只有一期月營收**，看不出趨勢，要三期才能判斷加速或見頂
